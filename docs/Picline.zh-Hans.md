# Picline 0.3.0

基于 Tendedero 的本地修改版。按上游许可证要求使用独立名称和图标，保留原作者版权声明。

Picline 是 Mac 菜单栏下的一条图片晾衣绳：把截图和复制的图挂成一排，用哪张取哪张。连续截图时剪贴板只留最后一张，挂到绳子上就不会被后面截的顶掉；要用的那几张一起选中，一起拖走。文件夹里选中几张「打开方式 → Picline」也能一次挂上。多个桌面都通用，也可以隔空投送或存到桌面。默认简体中文，可从菜单栏的「语言」切换到英文或跟随系统。

## 怎么把绳子放下来

| 操作 | 结果 |
| --- | --- |
| 指针碰到菜单栏 | 绳子立刻滑下来（只留 0.06 秒缓冲，挡掉只是从顶部穿过去的指针）。绳子上没有图时不下来 |
| 按住一个键再碰菜单栏 | 菜单栏 →「放下晾衣绳」→「需要按住按键」，可选 `⌘` / `⌥` / `⌃` / `⇧`（0.2.7 新增）。选了键之后不按就不放下来 |
| 点击菜单栏任意处 | 把绳子收起来 |
| 指针离开绳子超过 0.5 秒 | 自己收回去 |
| `Control + Option + T` | 显示 / 隐藏（菜单栏「快捷键」里可改） |

在哪块屏幕上贴顶，就下在哪块，并按那块屏幕的缩放比例绘制。全屏应用或演示模式下不打扰，除非主动用快捷键或菜单叫出来。

## 绳子上的每一张图

| 操作 | 结果 |
| --- | --- |
| 单击 | 选中这张（外面出现蓝色描边） |
| `Shift` + 单击 | 从上次选中的那张一路选到这一张，中间的全都选上；反着点也行 |
| `Command` + 单击 | 加选 / 取消这一张 |
| 双击 | 用「双击图片打开方式」里设定的应用打开，默认是系统关联 |
| 按住 0.45 秒，或触控板力触控 | 快速查看，左右方向键翻整条绳子 |
| 中键（带滚轮的鼠标） | 标记 |
| 拖进 app | 送一份副本过去，原图仍挂在绳上 |
| 拖进文件夹或桌面 | 存在那儿，图从绳上取下 |
| 拖到废纸篓 | 删除 |
| 拖动选中的图 | 选中的几张一起走：拖进聊天窗口一起发出去，拖进文件夹一起拷进去 |
| 点卡片左上角叉号 | 只取下这一张（选了一组也不会连带清掉别的） |
| 右键 | 见下一节 |

## 右键菜单

菜单里的每一项都**对整组生效**：选中三张，在其中任意一张上右键，「存储到桌面」就是三张一起存，「隔空投送」就是三张一起投送。只单击了一张时，仍然只对那一张。菜单项标题会带上张数，例如「存储到桌面 · 3 张」。

| 菜单项 | 做什么 | 什么时候出现 |
| --- | --- | --- |
| 复制 / 打开 / 快速查看 | 同双击、长按；复制只在这里（单击不再复制）。复制一组会写成多个文件：粘进访达是拷几份，粘进聊天窗口是发几个 | 总是 |
| 标记 | 打开标记窗口（录屏中不显示） | 总是 |
| 在访达中显示 | 在访达里定位文件，一组就一起选中 | 总是 |
| 隔空投送 | 系统窗口列出附近设备，选一台发过去；一组就是一次投送多张，图不从绳上取下 | 每一张的文件都还在时；有一张被移走则置灰 |
| 存储到桌面 | 每张都存一份。截图文件夹里的图是移动过去，别处来的图是复制一份，不会把原来的文件从它所在的文件夹里搬走 | 图来自截图文件夹或剪贴板时 |
| 丢弃 / 移到废纸篓 | 从绳上取下并删除文件（选了一组就整组） | 同上 |
| 取下 | 只从绳上取下，文件留在原处（选了一组就整组） | 图是外部引用的文件时 |
| 取下左侧 / 右侧全部 | 一次清掉一半 | 那一侧还有图，**且只选中一张**时；选了一组就置灰 |
| 全部取下 | 把整条绳子收干净，一张不留 | 总是 |

快速查看和标记只作用于一张：快速查看本来就能翻整条绳子，标记一次只编辑一个文件。

## 从访达挂图

选中一张或多张图片，右键 → **打开方式** → **Picline**，图会复制一份进应用并挂到绳上。QSpace 等第三方文件管理器的「打开方式」走同一套机制，同样可用。也可以把图片直接拖到 Picline 的图标上。

## 接入截图工具

**接收剪贴板图片**（菜单栏里勾选）与监听目录相互独立。开启后，从 Finder、微信、网页、截图工具复制的图片都能接收，不需要先添加其文件夹；纯文本和普通文件的图标不会被当成图片。支持一次复制多个图片文件。

需要按文件夹接收时，菜单栏 → **接收其他文件夹的截图** → **添加文件夹…**。可以是截图工具的保存目录，也可以是它自己的临时目录（例如 Shottr 的 `~/Library/Containers/cc.ffitch.shottr/Data/tmp/cc.ffitch.shottr`）。按日期创建的子文件夹也受监视，添加目录时不会导入原有图片。

可选的 **接收系统截图** 会把 macOS 自带截图工具的输出改到本应用的截图文件夹并关闭浮动缩略图，退出或关闭选项时恢复设置。此选项不会改变 Shottr 或 Snapzy 的配置；主要用第三方工具时，首次询问选「暂不开启」即可。

去重按解码后的像素和方向精确匹配：同一张图从目录、剪贴板或多个工具进来只挂一次；裁剪、标注、缩放或重新压缩过就算不同内容。录屏不参与图片去重。

## 双击图片打开方式

菜单栏 → **双击图片打开方式**，可选 **系统默认**、**预览**、**Shottr**、**Snapzy**，或用 **其他应用…** 指定别的编辑器。选择会保存，之后双击卡片或右键「打开」都交给它。未安装的应用显示为不可选；选定后被移除或打开失败，会提示临时用系统默认或取消，原选择保留。录屏继续用系统默认播放器。

## 文件放在哪

- 文稿、桌面等普通目录继续引用原文件：取下不删原文件；明确选「移到废纸篓」才删；标记直接编辑那个文件。
- 系统临时目录里的图片会自动保存一份私有副本，源文件被清理后副本仍留在绳上。副本位于 `~/Library/Application Support/Picline/Screenshots/`，权限为仅当前用户可读写。
- 图片上限为 64 MiB、8000 万像素；录屏沿用原有的收件箱支持，不受这条限制。
- 没有截图区域元数据的图片直接挂入，有区域元数据的沿用飞入动画。

## 从源码构建

```sh
scripts/build-picline.sh release    # 通用二进制（arm64 + x86_64），产物在 build/Picline.app
scripts/package-dmg.sh              # 打包成 build/Picline-<版本>.dmg
swift test --disable-sandbox        # 95 项测试
```

构建使用 ad-hoc 签名，不安装到「应用程序」，也不做 Developer ID 或公证。菜单栏 → **开源声明** 可查看上游来源、原作者与完整许可证，内容随应用打包，离线可读。

## Windows 版

`windows/` 里是同一套交互的 Windows 实现：Rust 写的手写 Win32 + GDI+，一个 exe，不用安装。贴顶唤出（也可要求按住 `Ctrl` / `Alt` / `Shift`）、快捷键可自行录制、截图与复制的图自动挂上、单击选中、`Shift` 连选、`Ctrl` 加选、双击预览、右键菜单、拖进聊天窗口或文件夹，规则与 Mac 版一致。在 Mac 上用 llvm-mingw 交叉编译出 x64 与 ARM64 两个 exe，详见 [`../windows/README.md`](../windows/README.md)。

## 最近几个版本

- **0.3.0** — 会自己去问有没有新版本（系统通知 + 菜单项 + 当场查询）；第一次装上绳子自己下来介绍自己 9 秒。Windows 同步到 0.2.5：不再每拖一次留一个临时文件，取下卡片时把自己生成的文件丢进回收站。
- **0.2.9** — Windows 端补齐：翻页预览、空绳时托盘变淡、开机自启、检查更新、标记、WebP/HEIC。macOS 端代码未改。Windows 版本号改为一位数递增（`0.1.9` 之后进 `0.2.0`），这一版是 0.2.4。
- **0.2.8** — 空绳子不再贴顶出现：去点菜单栏不会被一条空绳挡一下。有图时手感不变。Windows 端补上应用图标，托盘为随深浅色切换的单色版。
- **0.2.7** — 贴顶唤出可以要求按住一个键（`⌘` / `⌥` / `⌃` / `⇧`），不按不放绳；选了一组时左右两侧置灰。Windows 端快捷键也不再写死。
- **0.2.6** — 一次选中几张一起用：Shift 连选、整组拖拽、右键菜单对整组生效；单击不再复制；指针碰到菜单栏立刻放绳；卡片右键加「全部取下」。
- **0.2.5** — 空绳子也能贴顶唤出，应用不会像没在跑。
- **0.2.4** — 从访达挂图的主入口改为「打开方式 → Picline」，不再依赖时有时无的「服务」菜单。
- **0.2.3** — 访达服务，以及收图链路的修复。
