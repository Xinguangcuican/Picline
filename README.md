## 这是什么

Picline 是 [Tendedero](https://github.com/alejandrobujan/tendedero) 的一个修改分支。上游由 Alejandro Buján 编写；**老张** 在它上面强化了收图能力（读第三方截图工具的剪贴板、跨工具去重、指定打开图片的应用），本仓库又修好了多桌面，加了隔空投送、长按预览、访达入口，以及一次选中几张一起用。

两个平台，同一套交互：

| | macOS | Windows |
| --- | --- | --- |
| 形态 | 菜单栏图标 + 屏幕顶部的绳子 | 托盘图标 + 屏幕顶部的绳子 |
| 安装 | `Picline-0.3.0.dmg`，拖进「应用程序」 | 一个 exe，双击就跑，不用安装 |
| 加选键 | `Command` | `Ctrl` |
| 界面语言 | 11 种，可切换 | 中文 |

## 最常用的两个场景

### 一、截一张挂一张，最后一起拖走

系统剪贴板只记得最后一张图。截第二张的时候，第一张就没了 —— 连着截五张，要么一张一张存盘，要么回头去文件夹里翻。

Picline 把每张图都挂到屏幕顶上那条绳子上，一张挨着一张摆开，后面截的不会把前面挂的顶掉。截完要发的时候，在绳子上点几张选中，整组拖进微信、飞书、PPT 或任何能接图的窗口 —— 拖几张过去就是几张。

不用先存盘，也不用在窗口和文件夹之间来回切。

### 二、文件夹里的图，挑几张一起挂上

一批图躺在文件夹里，只需要其中三张发给某个人，或者丢进编辑器里排版 —— 不必一张一张往软件里拖。

在访达里选中那几张，右键「打开方式 → Picline」；Windows 上是选中后右键「挂到 Picline」。选几张就挂几张，接着照上面那样整组拖走。

挂上的是副本，之后把原文件移走或者删掉，卡片都还在。

# macOS

## 安装

1. 下载 `Picline-0.3.0.dmg`，双击打开，把 `Picline` 拖进「应用程序」。
2. 首次打开会被 Gatekeeper 拦（本版未做公证，属正常现象）。两种放行办法：
   - 系统设置 → 隐私与安全性 → 拉到下面点「仍要打开」，再确认一次；
   - 或终端执行：`xattr -dr com.apple.quarantine /Applications/Picline.app`
3. 启动后菜单栏出现图标。要收截图，先在菜单里勾选「接收剪贴板图片」。

## 怎么把绳子放下来

| 做法 | 结果 | 起始版本 |
| --- | --- | --- |
| 指针碰到菜单栏 | 立刻放下来，只留 0.06 秒缓冲挡掉只是穿过去的指针 | 0.1.x；0.2.6 起几乎即时 |

| 空绳子不贴顶下来 | 没挂图时贴顶没有任何反应，去点菜单栏不会被挡；用快捷键或菜单叫出来仍能看到空绳和那句提示 | 0.2.8（0.2.5–0.2.7 会下来） |
| 第一次装上 | 绳子自己下来 9 秒，写两行：截图会挂在这里；指针推到屏幕最上面，它就会下来 | **0.3.0** |
| 点击菜单栏任意处 | 把绳子收起来 | 0.1.x |
| 指针移开超过 0.5 秒 | 自己收回去 | 0.1.x |
| `Control + Option + T` | 显示 / 隐藏，可在「快捷键 → 更改快捷键…」里改 | 0.1.9 |

在哪块屏幕上贴顶就下在哪块，按那块屏幕的缩放比例绘制。全屏应用或演示模式下不打扰，除非主动用快捷键或菜单叫出来。

| 菜单项 | 做什么 | 起始版本 |
| --- | --- | --- |
| 复制 / 打开 / 快速查看 / 标记 | 复制只在这里（单击不再复制）；复制一组会写成多个文件 | 0.1.9 起；0.2.6 改为对整组生效、单击不再复制 |
| 在访达中显示 | 定位文件，一组就一起选中 | 0.1.9 |
| 隔空投送 | 系统窗口列出附近设备，一组就是一次投送多张 | 0.2.1 |
| 存储到桌面 | 每张存一份；截图文件夹里的移过去，别处来的复制一份 | 0.1.9 |
| 丢弃 / 取下 / 移到废纸篓 | 从绳上取下，按来源决定是否删文件（一组就整组） | 0.1.9 |
| 取下左侧 / 右侧全部 | 一次清掉一半；**选了一组就置灰** | 0.1.9 起；0.2.7 置灰 |

## 收图

- **剪贴板**：截图工具复制的图、浏览器里复制的图、访达里复制的图片文件都能接收，不需要先添加文件夹。菜单里勾选「接收剪贴板图片」才开启。
- **监视文件夹**：菜单栏 →「接收其他文件夹的截图」→「添加文件夹…」，可以是截图工具的保存目录，也可以是它的临时目录；按日期创建的子文件夹也受监视。
- **系统截图**：「接收系统截图」会把 macOS 自带截图工具的输出改到应用自己的文件夹并关掉浮动缩略图，退出或关掉选项时恢复。
- **去重**：按解码后的像素和方向精确匹配，同一张图从目录、剪贴板或多个工具进来只挂一次；裁剪、标注、重压过算不同内容。

## 从访达挂图

选中一张或多张图片，右键 →「打开方式」→「Picline」，图会复制一份进应用并挂到绳上。QSpace 等第三方文件管理器的「打开方式」同样可用，也可以直接把图拖到 Picline 的图标上。

# Windows

> Windows 每改一版，版本号第三位加一；满 9 就进第二位（`0.1.9` 之后是 `0.2.0`），所以永远只有三位、没有 `0.1.13` 这种两位数。这一版接着往下数，是 **0.2.5**：早先那几个两位数的版号（`0.1.10`–`0.1.13`）按同一规则现在是 `0.2.0`–`0.2.3`。

Windows 端另有独立仓库 [`Xinguangcuican/Picline-Windows`](https://github.com/Xinguangcuican/Picline-Windows)，提交历史单独可查，Windows 的 exe 也在那边单独发版；本仓库的 `windows/` 是它的镜像，方便一处看两端。

## 安装

1. 下载 `Picline-0.2.5-win-x64.exe`（绝大多数机器）或 `Picline-0.2.5-win-arm64.exe`（骁龙本等 ARM 机器）。

3. 首次运行会被 SmartScreen 拦一下（未签名）：更多信息 → 仍要运行。

## macOS 与 Windows 不一样的地方

两个版本交互对齐，但有些动作天生不同，这里是全部差异，没有隐藏项：

| 事项 | macOS | Windows |
| --- | --- | --- |
| 双击 | 用默认应用或自选应用打开文件 | 全屏预览窗（压暗桌面、放大图片） |
| 快速查看 / 标记 | 有：长按或力触控快速查看，中键标记 | 标记有（右键 →「标记」，用系统画图，存回原文件）；快速查看没有，用双击预览代替 |
| 隔空投送 | 有 | 没有；用「复制图片」粘到聊天窗口，或直接拖 |
| 加选键 | `Command` | `Ctrl` |
| 放下绳子的快捷键 | 可自定义（默认 `⌃⌥T`），菜单栏「快捷键 → 更改快捷键…」 | 可自定义（默认 `Ctrl + Alt + T`），托盘「快捷键：…」，按一遍新组合 |
| 挂图入口 | 访达「打开方式 → Picline」 | 资源管理器右键「挂到 Picline」 |
| 界面语言 | 11 种，可切换 | 中文 |
| 图片格式 | 系统 ImageIO 能解的都能挂（含 webp、heic） | GDI+ 与系统 WIC 能解的都能挂（webp / heic 取决于机器上装没装对应解码器） |
| 虚拟桌面 | 所有 Space 通用 | 切换虚拟桌面时窗口不跟随 |
| 开机自启 | 菜单里勾选 | 托盘菜单里勾选（写 HKCU 的 Run 键） |

## 更新记录

完整改动见 [`CHANGELOG.md`](CHANGELOG.md)，这里只记最近几版。

- **0.2.9 — 2026-11-04（macOS）/ 0.2.4（Windows）** Windows 端补齐六件事：双击预览可 `←` `→` 翻页、空绳时托盘变淡、开机自启、检查更新、右键「标记」且卡片跟随保存、WebP / HEIC / AVIF 可挂。macOS 端代码未改。Windows 版本号改为一位数递增（`0.1.9` 之后进 `0.2.0`），按累计版数这一版是 `0.2.4`。

## 多桌面是怎么修的

带 `canJoinAllSpaces` 的 `NSPanel` 一旦 `orderOut` 再 `orderFront`，系统可能把它永久绑在某个 Space 上 —— 这是上游 [issue #80](https://github.com/alejandrobujan/tendedero/issues/80) 的症状。解法不是去修那个窗口，而是**发现它不在当前桌面时，直接重建一个新窗口**。全部改动集中在 `Sources/Tendedero/AppDelegate.swift`，共 31 行；之后所有版本都建在这个修法之上。

## 发版

打一个 tag 推上去，编译、打包、发 Release 全部由 GitHub Actions 完成：

```sh
git tag v0.2.9
git push origin v0.2.9
```

1. **版本号取自 tag**，代码里的任何数字都不用改。
2. **发布说明取自 `CHANGELOG.md`** 里对应版本的段落，末尾自动附上安装说明。
3. **macOS 产物自动上传**；Windows 的 exe 体积小、又不需要签名，发版后手动补传一次：

```sh
gh release upload v0.2.8 windows/dist/Picline-0.1.10-win-*.exe \
  windows/dist/Picline-0.2.5-win.zip
```
